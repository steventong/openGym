# 网页与原生 iOS 功能对照

范围：个人用户页面。排除 `frontend/src/views/Admin.jsx`、`AdminCoach.jsx` 及管理员服务配置。所有实现位于 `native-ios/`，复用现有服务协议和网页纯计算函数；没有修改网页、Android 或服务端。

这是一份逐项迁移清单，不代表全部网页功能已经完成。2026-10-29 本次补齐以个人资料、动作库、计划工具和进步统计为主；原有训练与 Apple Watch 并行改动保留。

## 保存与验证

个人设置仅修改相应字段。日期记录与自定义动作按日期或 ID 更新单条记录；遇到 409 读取最新文档后重放。对同一字段的并发修改会提示冲突。保存后读回确认，保留未知字段。围度重复提交按实际测量值判断，避免响应丢失后因 `t` 时间戳不同而失败。

`PersonalFeaturesTests.swift` 覆盖单位换算、健康样本归属、进阶参数校验、分组统计、模板文件换算与隐私边界、重复训练、删除修复、元数据兼容、库存时间戳、日期冲突和 409 重放。全套 XCTest 最终结果见 README 的本次验证记录。

模拟器使用独立 `OpenGym Personal Parity QA` 和 `scripts/personal-qa-server.mjs`（仅 `127.0.0.1:19386`、虚构数据、配对码 `QA`）。已通过界面完成：

- 新增 79.5 cm 腰围，趋势从一个点变为两个点，历史与服务器读回一致。
- 默认休息由 90 改为 105 秒，参考成绩改为历史最佳，服务器读回一致。
- 导入三份全身模板，保留原计划、原周排期及未知扩展字段。
- 新建自定义动作、选择胸肌为主肌群、收藏，动作库及服务器读回一致。

证据保存在忽略目录 `artifacts/personal/`。测试未修改真实账号数据，未发布 TestFlight，也未把模拟器验证描述为真机验证。
